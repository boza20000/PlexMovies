1. Install docker on you computer

2. Go to the search tab and find postgreSql official image

3. Run the container

4. Now you have container running postgreSql server

5. Add dependencies for jpa and hibernate in pom.xml from maven central

6. Open intellij and update your properties file with the url, password and username provided

7. Run you project it should run with nop errors or connection problems

8. Install DBeaver or something similar.

9. Run it and add new connection where you fill your DB information

10. Test the connection it should be green and you should see the DB under 'Connections'
